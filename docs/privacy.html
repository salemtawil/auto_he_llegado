Politica de privacidad

Esta politica explica que datos utiliza Auto He Llegado, con que finalidad y donde se procesan.

Ultima actualizacion: 15 de septiembre de 2026.

Responsable y alcance

Auto He Llegado es una aplicacion de escritorio de acceso privado. Esta politica se aplica a las personas que crean una cuenta, utilizan sus procesos o envian videos mediante la aplicacion.

Datos que se procesan

  • Nombre de usuario, correo electronico, estado de aprobacion y permisos de acceso.
  • Nombre, tamano, duracion, dimensiones y huellas tecnicas del video, utilizadas para detectar cargas repetidas.
  • El video que el usuario selecciona voluntariamente para enviarlo a Google Drive.
  • Estados de revision, fechas, resultados y registros tecnicos necesarios para operar y diagnosticar la aplicacion.

Uso de Google Drive

La aplicacion solicita el permiso https://www.googleapis.com/auth/drive.file para crear el video seleccionado por el usuario en la carpeta configurada para el servicio. No solicita permiso para consultar o administrar todos los archivos de Google Drive.

La autorizacion de Google se guarda localmente en el equipo para evitar solicitar acceso en cada uso. El usuario puede revocarla desde la configuracion de seguridad de su cuenta de Google.

El uso y la transferencia de informacion recibida de las API de Google cumplen la Politica de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de uso limitado.

Finalidades

Los datos se utilizan para autenticar usuarios, controlar el acceso, recibir contribuciones de video, detectar duplicados, permitir la revision administrativa, notificar la recepcion y resolver fallos operativos.

Servicios utilizados

Auto He Llegado utiliza Supabase para autenticacion y registros operativos, Google Drive para almacenar los videos enviados y Telegram para notificar al administrador con el nombre del usuario, datos basicos del archivo y un enlace al video. Estos proveedores procesan informacion conforme a sus propias condiciones y politicas.

Conservacion y eliminacion

Los datos se conservan mientras sean necesarios para operar el sistema, mantener la auditoria y revisar las contribuciones. El usuario puede solicitar la eliminacion de su cuenta y de los datos asociados mediante el correo de contacto. Algunas referencias tecnicas pueden conservarse cuando sean necesarias para prevenir duplicados o resolver incidencias.

Seguridad y control del usuario

Se aplican controles de acceso y permisos para limitar el tratamiento de la informacion. Ningun sistema es infalible; cualquier incidencia o solicitud relacionada con datos personales puede comunicarse al responsable.
